# 갈만한 거리의 집 — 프로그램의 목적과 개요

## 이름과 목적

- 정식 이름: **갈만한 거리의 집**
- 줄임말: **갈만집**
- 목적: 사용자가 설정한 소요 시간 안에 목적지로 갈 수 있는 아파트를 지도에서 찾아보고 부동산 정보를 조회할 수 있는 웹앱을 제공한다.

## 핵심 기능 요구사항

- 사용자가 목적지와 최대 소요 시간을 설정하여 검색한다.
- 해당 시간 안에 목적지로 이동할 수 있는 경로를 찾는다. 이동 방향은 아파트에서 목적지로 가는 방향을 기준으로 한다.
- 해당 경로의 버스 정류장과 지하철역 근처 아파트의 부동산 정보를 조회한다.
- 첫 버전의 지원 지역은 **서울특별시와 경기도**다.
- 매매·전세·월세의 **실거래 내역**과 아파트 단지 정보를 조회 대상으로 한다.
- 현재 판매·임대 중인 매물은 앱 안에 표시하지 않고, 사용자가 확인할 수 있는 **네이버 부동산 외부 링크**를 제공한다.
- 소요 시간은 집에서 목적지까지의 도보·대기·탑승·환승 시간을 포함한 예상 총 소요 시간을 기준으로 한다. 추정값과 실제 운행 상황의 차이를 사용자에게 알린다.

## 기본 원칙

갈만집은 부동산 조회만 제공하는 클라이언트 웹앱이다. 서버 관리 부담을 줄이기 위해 별도의 백엔드 서버를 운영하지 않는다.

- 사용자는 부동산 화면과 정보를 조회할 수 있다.
- 어떠한 사용자 정보도 저장하지 않는다.
- 북마크를 포함한 사용자별 데이터를 저장하지 않는다.
- 서버 운영이나 사용자 데이터 저장이 필요한 기능은 현재 범위에 포함하지 않는다.
- 개발과 서비스 운영에 비용을 지불하지 않는 것을 전제로 하며, 유료 서비스나 무료 한도 초과 과금에 의존하지 않는다.

## 구성과 배포

- **실행 방식:** 브라우저에서 실행되는 클라이언트로 구성한다.
- **호스팅:** GitHub Pages로 정적 웹앱을 배포한다.
- **지도:** Kakao 지도 API를 사용한다.
- **백엔드:** 프로젝트 자체의 백엔드 서버는 두지 않는다.

지도 API와 같은 외부 서비스의 이용은 별도 백엔드 서버를 운영하는 것과 구분한다. 외부 서비스를 연동할 때에도 정적 클라이언트만으로 동작한다는 제약을 지켜야 한다.

공개 교통·아파트·실거래 자료를 정적 데이터로 배포하고 브라우저에서 탐색하는 방향을 채택한다. 공개 자료의 배포는 사용자 정보 저장과 구분한다. 채택한 기술과 데이터 출처, 선택 이유 및 검증 과제는 [기술 방향과 데이터 조사](technical-decisions.md)를 따른다.

## 향후 앱 제공 방식

추후 갈만집을 앱으로도 출시할 예정이다. 앱에서 같은 기능을 별도로 다시 개발하지 않고, 웹앱을 iframe으로 임베드하여 제공한다.

웹앱을 공통 구현으로 유지하며, 개발 시 브라우저 직접 접속과 앱 내 iframe 임베드 환경을 함께 고려한다. 앱에서도 조회 전용 및 사용자 데이터 비저장 원칙을 유지한다.

## 아직 정하지 않은 사항

- 서울·경기도 전체를 위한 교통·아파트 좌표 자료의 확보 범위와 품질
- 시간표·보행망을 반영한 후속 경로 정확도 개선 기준. 초기 평균 시간 추정의 결정 배경은 [교통 자료 안내](search-data-setup.md)를 참조한다.
- 네이버 부동산 링크의 구체적인 URL 및 단지 연결 방식
- 상세 조회 기능과 화면 구성
- 앱 플랫폼 및 iframe을 포함할 앱의 구체적인 구성

이 사항들은 추후 결정하여 문서로 기록한다.

## 문서 관리

`docs/`에는 프로젝트의 목적과 개요, 개발 시 지켜야 할 규칙, 프로젝트 메타데이터를 기록한다. 새 문서를 추가하면 루트 `AGENTS.md`의 문서 색인에 등록한다.

`AGENTS.md`와 `docs/`에는 코드나 설정 파일만 보고 알 수 있는 내용을 중복 기록하지 않는다. 구현 세부사항은 원본 코드와 설정 파일을 참조하고, 문서에는 코드에서 드러나지 않는 목적·제약·규칙·결정 배경·메타데이터를 남긴다. 이는 코드 변경 후 문서가 실제 구현과 달라지는 문제와 이중 관리 부담을 방지하기 위한 원칙이다.
