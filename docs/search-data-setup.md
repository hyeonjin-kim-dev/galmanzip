# 검색에 필요한 교통 자료 준비

## 아직 필요한 자료

소유자는 KTDB 자료를 다운로드했다. 작업 환경에서 원본 파일을 읽고 서울·경기도의 버스·철도 자료를 변환·검증하는 과정이 남아 있다. 현재 진행 상황은 [작업 인계](../HANDOFF.md)를 참조한다. 실거래가 자료의 수집·연결 역시 후속 과제다.

무료·백엔드 미운영 원칙을 유지하기 위해 공개 교통 자료를 가공해 배포하는 방향을 선택했다. 카카오 지도 키만 등록하는 것으로 이 교통망 자료가 생기지는 않는다. 가상 정류장·소요시간·아파트를 운영 자료로 채우지 않는다.

## 소유자가 한 번 할 일

2026년 11월 1일 작업에서 확인한 KTDB 공식 제공 절차다. 신청에는 신청자의 소속과 이용 목적 입력이 필요하므로 소유자가 직접 진행한다. 앱 이용자의 개인정보를 수집하는 절차와는 별개다.

소유자는 아래 신청·다운로드를 완료했다. 다시 신청할 필요는 없으며, 아래 절차는 향후 자료 갱신 때 참고한다.

1. [국가교통DB 자료신청](https://www.ktdb.go.kr/www/contents.do?key=202)을 연다.
2. **교통분석자료 신청 → 교통망 GIS DB → 대중교통 → 대중교통**에서 **GTFS 기반정보**를 선택한다. 이 경로는 [공식 제공 공지](https://www.ktdb.go.kr/www/selectBbsNttView.do?bbsNo=2&key=45&nttNo=3831)에 명시되어 있다. 화면에 추가 인증 절차가 나오면 안내에 따라 본인 정보로 진행한다.
3. 자료 신청서에서 소속·분류를 사실대로 작성한다. 이용 목적은 아래 문안을 사용할 수 있다.

   > 서울·경기도에서 목적지까지의 예상 대중교통 소요시간으로 아파트 위치를 조회하는 무료 웹앱 ‘갈만한 거리의 집’을 개인 개발합니다. 제공받은 교통 자료로 경로 계산용 자료를 가공하고 GitHub Pages에서 공개하여 브라우저에서 계산할 계획입니다. 이용자 개인정보는 저장하지 않으며, 자료 출처와 기준일을 표시합니다.

4. [공식 신청방법](https://www.ktdb.go.kr/www/contents.do?key=203)의 순서에 따라 신청서 작성과 이용자 만족도 조사 후 자료를 다운로드한다. 교통 자료와 함께 제공되는 설명서·파일 명세·이용 조건도 보관한다.
5. 다운로드한 교통 자료와 설명서·이용 조건을 에이전트에게 전달한다. 신청자의 개인정보나 계정 비밀번호는 전달하지 않는다. 변환·검증·저장소 반영·자동 배포는 에이전트가 이어서 진행한다.

첨부 파일을 작업 환경으로 전송하는 도구에는 파일당 32MiB 제한이 있다. 소유자가 사용하는 Windows에서 큰 원본을 전달할 때는 [파일 분할 도구](../scripts/split-gtfs-upload.ps1)를 사용한다. 분할 파일과 함께 생성되는 검증 정보도 전달해야 원본이 온전히 복원되었는지 확인할 수 있다. 파일 분할은 전송을 위한 과정이며, 운영 데이터의 변환이나 공개 배포를 대신하지 않는다.

## 확인한 사실과 남은 검증

- KTDB는 자료를 무상 제공하며 일반이용자도 신청 대상으로 안내한다. 별도 유료 경로 API나 서버 계약이 필요한 절차는 아니다.
- [2026년 10월 26일 공지](https://www.ktdb.go.kr/www/selectBbsNttView.do?bbsNo=2&key=45&nttNo=3831)에 따르면 해당 자료는 **2025년 3월의 평일 하루**를 기준으로 한다. 전국 버스·도시철도 등을 포함하며, 수정본은 2026년 10월 27일부터 제공한다. 현재 실시간 운행 정보로 간주하지 않는다.
- 같은 공지는 식별자 체계 등이 표준화되지 않은 파일럿 자료라고 명시한다. 다운로드한 파일의 실제 명세를 확인하기 전에는 표준 GTFS 변환기로 바로 처리할 수 있다고 단정하지 않는다.
- [KTDB 저작권정책](https://www.ktdb.go.kr/www/contents.do?key=154)은 KTDB가 저작재산권 전부를 보유한 자료의 자유이용과 구체적인 출처 표시를 안내한다. 실제로 받은 자료의 조건과 권리 범위를 확인한 뒤 가공 자료의 공개 배포 여부를 판단한다. 무료 다운로드를 모든 자료의 무조건적인 재배포 허용으로 해석하지 않는다.
- 수령 후 운행 방향, 노선별 경유 순서, 구간 시간, 배차·환승 제약과 서울·경기 포함 범위를 검증해야 한다. 기준일이 오래되었거나 자료에 없는 노선을 현재 이용 가능하다고 표시하지 않는다.
- 데이터 계약과 검증 로직은 [검색 자료 타입](../src/search/types.ts)과 [경로 계산](../src/search/routing.ts)을 참조한다. 명세를 문서에 복제하지 않는다. 실제 자료의 변환기는 원본 명세를 확인한 뒤 작성한다.

## 추가 키와 매물 조회

목적지·아파트 장소 조회에는 기존 Kakao 지도 JavaScript 키를 사용한다. 이 단계에서 REST API 키나 공공데이터 인증키를 새로 받아 브라우저에 넣지 않는다. 무료 쿼터의 실제 적용 범위는 [Kakao 설정 안내](kakao-map-setup.md)를 따른다.

Kakao 장소 검색의 아파트 정보는 현재 매물이나 실거래가가 아니다. 네이버 부동산의 개별 단지 식별자는 아직 검증하지 않았으므로, 확인한 [공식 진입 주소](https://land.naver.com/)에서 단지명으로 검색하도록 안내한다. 단지 연결 주소를 추측하거나 매물 자료를 수집하지 않는다.
