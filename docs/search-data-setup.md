# 이전 교통 자료 수령 기록

사용자가 전달한 KTDB 자료는 자체 경로 계산 금지 결정 이전에 검토한 자료다. 현재 경로 계산에는 사용하지 않는다. 카카오 전환의 제약과 필요한 외부 절차는 [카카오 대중교통 길찾기 전환](kakao-transit-setup.md)을 따른다.

2026년 11월 1일 `대중교통GTFS(2025년 기준)_261027.zip`의 분할 파일 여섯 개와 검증 정보를 대조해 원본 크기·SHA-256 일치를 확인했다. 동봉 설명서·노선 엑셀도 검토했다. 원본은 작업 환경의 저장소 밖 `/workspace/gtfs-import/ktdb-original.zip`에 있으며, 이후 다른 환경에도 존재한다고 가정하지 않는다.

자료는 [KTDB 제공 공지](https://www.ktdb.go.kr/www/selectBbsNttView.do?bbsNo=2&key=45&nttNo=3831)의 2025년 3월 평일 하루 기준이었다. KTDB 전용 수단 코드와 분석용 달력 등으로 현재 실시간 운행을 보장하지 못했다. 과거 검증 보고서와 변환 결과는 [이전 커밋](https://github.com/hyeonjin-kim-dev/galmanzip/tree/56afad3/public/data)에서 확인할 수 있다. 이를 현재 서비스 자료로 되돌려 사용하지 않는다.

사용자는 이미 신청·다운로드·전달을 마쳤다. 다시 같은 자료를 요청하지 않는다. 실거래가 자료 수집과 아파트 단지 연결은 별도의 후속 과제다.
