# 교통 자료 출처와 제약

## 수령과 이용 근거

사용자가 신청·다운로드한 `대중교통GTFS(2025년 기준)_261027.zip`을 전달했다. 2026년 11월 1일 분할 파일 여섯 개와 검증 정보를 대조해 원본 크기·SHA-256 일치를 확인하고, 동봉 설명서와 노선 엑셀을 검토했다. 원본은 작업 환경의 저장소 밖 `/workspace/gtfs-import/ktdb-original.zip`에 있다. 다른 환경에도 존재한다고 가정하거나 사용자에게 같은 자료의 재전달을 반복 요구하지 않는다.

- 출처: [KTDB 제공 공지](https://www.ktdb.go.kr/www/selectBbsNttView.do?bbsNo=2&key=45&nttNo=3831)
- 이용 근거: [KTDB 저작권 정책](https://www.ktdb.go.kr/www/contents.do?key=154)의 출처 표시 조건을 확인했다. 서비스에서도 원출처와 가공 자료임을 알린다. 이후 다른 출처로 보완할 때는 해당 자료의 조건을 별도로 확인한다.
- 검증한 가공 자료와 원본 식별 정보: [배포 자료](../public/data/transit.json), [검증 보고서](../public/data/transit-audit.json)
- 원본 해석·제외 기준의 근거: [변환 코드](../scripts/build-transit.py), [변환 검사](../tests/test_build_transit.py)

## 기준일과 품질 제약

동봉 설명서에 따른 기준은 **2025년 3월 평일 하루**다. 파일명의 배포일이나 분석용 달력의 넓은 유효기간을 현재 운행일·최신 시간표로 해석하지 않는다. 주말·공휴일·새벽·심야·실시간 운행을 검증한 자료도 아니다.

KTDB의 수단 코드와 분석용 달력은 일반 GTFS의 관례와 다르다. 원본의 노선 설명과 운행 순서를 확인해 해석해야 한다. 승차 대기를 제외한다는 현재 결정은 [경로 검색 원칙](routing-policy.md)을 따른다. 원본의 배차 관련 정보를 현재의 실시간 도착 정보로 오인하지 않는다.

서울·경기 아파트의 경로가 행정 경계에서 끊기지 않도록 인천 연결 노선도 검토 범위에 포함한다. 아파트 지원 지역을 인천으로 확대하는 결정은 아니다. 일부 농촌·분기 노선은 자료에서 빠져 있으며, 여주시 관할 버스 노선도 원본에서 확인되지 않았다. 여주 철도가 있다는 사실과 버스망이 확보됐다는 주장을 구분한다.

평균 시간과 직선거리 기반 보행 추정에는 강·도로·출입구·보행 제한이 반영되지 않을 수 있다. 자료에 포함된 무환승을 먼저 찾더라도 모든 현재 직통 노선을 찾거나 실제 오차가 10분 이내라고 보장할 수 없다. 선택 경로의 도보 선형은 [별도 공개 보행망](walking-network.md)을 근거로 하며, 전체 검색의 보행 시간 검증과 최신 교통 자료·누락 노선 보완은 후속 과제다.

지도 경로 표시를 위해 원본 ZIP을 다시 확인했으며 도로 선형인 `shapes.txt`는 포함되어 있지 않았다. 정류장 순서와 좌표를 연결한 선을 실제 버스 주행선·철도 선형·보행 경로로 오인하지 않도록 화면에서 구분한다. 별도 근거 없이 이미지처럼 도로를 따라가는 모양을 만들어 내지 않는다.

사용자의 도로 이탈 개선 요청에 따라 별도의 버스 도로 좌표를 미리 확보해 정적으로 제공할 수 있도록 준비한다. 최초 승인과 실제 자료 확보 여부는 [버스 도로 좌표 안내](bus-route-shapes.md)를 따른다. 제공기관의 현재 선형과 기존 KTDB 정류장 순서가 일치하지 않는 경우 임의로 보정하지 않는다.

버스 종류는 동봉 노선 엑셀의 `유형`과 `route_cate정의`, 지하철의 노선 구분은 원본 노선명을 근거로 한다. 원본에는 노선 색상 값이 없으므로 색은 가독성과 익숙한 노선 구분을 위한 갈만집의 표시 선택이며 실제 차량 도색·최신 공식 RGB와의 완전 일치를 보장하지 않는다. 대중교통 색상 구분은 [서울시 버스 안내](https://mediahub.seoul.go.kr/archives/143908), [서울시 지하철 안내와 노선도](https://news.seoul.go.kr/traffic/archives/1551?listPage=1)를 참고했다. 구체적인 표시 값은 [표시 설정](../scripts/transit-styles.json), 적용은 [변환 코드](../scripts/build-transit.py)를 참조한다. 이 표시 보완은 기준일이나 운행 자료를 최신화한 것으로 해석하지 않는다.

## 아파트 자료의 별도 과제

Kakao 장소 검색은 전체 아파트 명부가 아니다. 넓은 시간 범위에서는 반복 장소 조회가 지연의 주요 요인이며, 교통 경로 계산을 빠르게 해도 전체 조회가 즉시 끝나는 것은 아니다. 공공 아파트 좌표 명부 확보와 실거래가 연결은 별도의 후속 과제로 남긴다.
