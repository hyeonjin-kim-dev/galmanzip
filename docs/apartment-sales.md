# 아파트 매매 실거래가

## 선택 배경

사용자는 아파트 목록에서 최근 매매 실거래가를 확인하도록 요청했다. 현재 판매 중인 개별 매물의 호가가 아니라, 해당 단지에서 신고된 매매 계약을 참고 정보로 제공한다. 가격의 의미가 달라지지 않도록 계약일·전용면적·층과 공개 자료를 수집한 시점을 함께 확인할 수 있어야 한다.

[국토교통부 아파트 매매 실거래가 상세 자료](https://www.data.go.kr/data/15126468/openapi.do)를 사용한다. 2026년 11월 9일 공식 안내에서 무료·이용허락범위 제한 없음·자동승인·개발계정 트래픽 10,000을 확인했다. 기본 매매 자료보다 단지 일련번호와 도로명 주소가 풍부해 장소 검색 결과와 대조하기 위해 상세 상품을 선택했다. 시군구는 [행정표준코드관리시스템의 법정동 전체 자료](https://www.code.go.kr/stdcode/regCodeL.do?menuNo=101010100010)를 근거로 한다. 행정구역 변경 전후 신고 자료가 있을 수 있어 상위 시와 자치구를 구분해서 확인한다.

비용 미지출·서버 미운영을 유지하기 위해 공공 API는 자료 갱신 시에만 사용하고, 공개 자료를 가공해 GitHub Pages에서 제공한다. API 인증키를 브라우저에 넣지 않는다. 공용 실거래 자료의 보관은 사용자 검색 기록 저장과 구분한다. 수집·호출 상한·자동 갱신·배포 기준은 [자료 준비](../scripts/prepare_sales.py), [준비 워크플로](../.github/workflows/apartment-sales.yml), [배포 검사](../scripts/validate-sales.ts)를 참조한다.

## 가격 해석과 정확도

- 최근 거래의 초기 조회 범위는 최근 12개월로 정했다. 이 범위에 신고가 없는 단지의 과거 가격을 최신 가격인 것처럼 제시하지 않는다. 계약일을 기준으로 하며 해제된 거래는 제외한다.
- 같은 최신 계약일에 거래가 여러 개라면 그중 임의의 한 건을 대표 가격으로 고르지 않는다. 면적·층별 차이가 드러나게 한다.
- 같은 단지명이 다른 지역에서 쓰일 수 있다. 주소를 대조하고, 주소가 중복되거나 서로 충돌하면 확인되지 않은 가격을 추정해서 붙이지 않는다. 이름이나 지도상 거리만으로 연결하지 않는다.
- 신고 지연·정정·해제와 자료 갱신 지연으로 공개 가격은 달라질 수 있다. 수집일과 계약일을 구분하며 실시간 호가나 해당 집의 가치로 보장하지 않는다.
- 가격 자료 오류를 거래 없음으로 오인하지 않게 하고, 가격 로딩 때문에 경로 검색·목록 순서·읽던 위치를 바꾸지 않는다. 검사 기준은 [가격 대조 검사](../tests/sales.test.ts)와 [화면 검사](../tests/browser_sales.py)를 따른다.

## 최초 승인 절차

이번 연결에서 기존 인증키의 첫 요청은 HTTP 403·제공기관 코드 30을 반환했다. 사용자에게 아래 절차를 안내했고, 신청·승인 완료 후 같은 인증키로 실제 정상 응답을 확인했다. 설정을 다시 요구하지 않는다.

새 계정에서 연결할 때는 다음 절차를 따른다.

1. 공공데이터포털에 로그인하고 [아파트 매매 실거래가 상세 자료](https://www.data.go.kr/data/15126468/openapi.do)의 **활용신청**을 선택한다.
2. 웹사이트 개발에 맞는 활용 목적을 선택하고 설명에 `갈만집 웹앱의 아파트 최근 매매 실거래가 조회`를 입력한다. 필수 항목·이용 조건은 실제 신청 화면에 따라 확인한다.
3. **마이페이지 → 데이터활용 → Open API → 활용신청 현황**에서 해당 서비스의 승인 상태와 이용 기간을 확인한다. 다른 국토부 상품이나 버스 API의 승인으로 대체하지 않는다.
4. 기존 공공데이터 인증키 등록을 유지하고 에이전트에게 승인 완료를 알린다. 키 값을 채팅으로 보내지 않는다. 처음 등록하는 계정의 GitHub Actions 비밀 값 설정은 [기존 외부 자료 설정](bus-route-shapes.md)을 참조한다.

승인 전파 지연이나 권한 문제는 실제 응답 코드로 확인하며, 승인 즉시 모든 요청이 성공한다고 보장하지 않는다. 정상 연결 이후의 수집과 배포는 사용자가 매번 수동 실행하지 않도록 자동화한다.
