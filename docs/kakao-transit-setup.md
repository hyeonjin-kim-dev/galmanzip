# 카카오모빌리티 제휴 API의 이전 검토

이 문서는 제휴용 상품에 대한 검토 기록이다. 사용자는 현재 다른 무료 대안을 요청했다. 카카오맵 일반 대중교통 경로 조회 API는 별개 상품이며, [무료 대안 비교](technical-decisions.md)의 최신 검토를 우선 확인한다.

## 사용자 결정과 현재 제약

사용자는 자체 경로 계산을 금지하고 [카카오모빌리티 대중교통 통합 길찾기](https://developers.kakaomobility.com/affiliate/publictransit/multimodal)를 사용하도록 요청했다. 기존 KTDB 기반 경로·소요시간 추정을 대안으로 되살리지 않는다. API 실패나 한도 초과 때도 자체 계산으로 대체하지 않는다.

사용자는 아직 해당 API의 승인을 받지 않았다고 답했다. [제휴 안내](https://developers.kakaomobility.com/affiliate/)는 사전 제휴 계약을 요구한다. [시작하기](https://developers.kakaomobility.com/affiliate/publictransit/start.html)는 계정·앱 정보 전달과 계정 승인이 필요하다고 설명한다. 지도 JavaScript 키 등록이나 카카오맵 활성화로 이 승인을 대신할 수 없다.

[공개 가격표](https://developers.kakaomobility.com/price/)에는 이 제휴 대중교통 API의 무료 제공량·가격이 명시돼 있지 않다. 다른 카카오 API의 무료 쿼터를 이 상품에도 적용한다고 가정하지 않는다. 비용 미지출 원칙은 유지하며, 유료 계약·결제 설정을 진행하지 않는다.

## 소유자가 먼저 확인할 절차

1. [Kakao Developers](https://developers.kakao.com/)에서 현재 갈만집 앱의 앱 ID·이름을 확인한다. 계정 정보는 소유자가 관리한다.
2. 공식 문의처 `api.partners@kakaomobility.com`에 아래 내용을 문의한다. 공식 시작 안내에서 요구하는 계정 이메일·앱 ID·앱 이름·사업자명을 사실대로 작성한다. 사업자가 없다면 개인 개발이고 사업자가 없음을 설명하고 이용 가능 여부를 묻는다. 이 문서는 개인 개발자의 승인이 보장된다는 안내가 아니다.
3. 무료 이용 가능 여부·한도·승인 결과와 브라우저 호출 허용 조건을 확인한다. REST API 키·비밀번호를 채팅이나 공개 저장소에 보내지 않는다. 승인된 인증 방식이 확인되면 에이전트가 실제 호출·화면 연결·배포를 이어서 진행한다.

문의 문안:

> 무료 개인 부동산 조회 웹앱 ‘갈만한 거리의 집’을 개발 중입니다. GitHub Pages의 정적 웹앱이며 별도 백엔드를 운영하지 않습니다. 아파트에서 목적지까지의 소요시간·환승 횟수를 대중교통 통합 길찾기로 조회하려고 합니다. 비용 지불 없이 이용할 수 있는지, 무료 제공량과 호출 제한, 개인 개발자의 제휴 가능 여부를 알려 주세요. 공개 브라우저·iframe에서 직접 호출할 수 있는지와 CORS·REST API 키 보호를 충족할 공식 인증 방식을 함께 안내 부탁드립니다. 유료 계약이나 결제에는 동의하지 않습니다.

## 구현 전 확인할 점

- 공식 명세의 조회 단위는 출발지 한 곳과 목적지 한 곳이다. 목적지와 제한 시간만으로 서울·경기 전체의 출발지를 반환하는 API가 아니다. 후보 아파트 확보·호출 수·조회 범위를 별도로 정해야 한다.
- 기존 측정에서 자체 경로 계산보다 반복 장소 조회가 주된 지연 요인이었다. 길찾기 API 교체만으로 검색 시간이 단축된다고 보장하지 않는다. 전수 조회를 일부 결과로 몰래 바꾸지 않는다.
- 명세상 전체 소요시간에는 첫 탑승 대기가 제외된다. API의 정의를 사용자에게 정확히 알리고 임의 대기 시간을 더하지 않는다. 운행일 유형·출발 시각과 실제 응답 검증도 연결 전에 확정해야 한다.
- REST API 키가 필요하다. 브라우저 직접 호출의 허용 여부·CORS는 현재 미검증이다. GitHub Actions 비밀값으로 관리하더라도 클라이언트 번들에 포함하면 공개된다. 기존 서버 미운영 원칙을 바꾸거나 키를 공개하는 결정을 임의로 하지 않는다.
- 요청·응답 처리의 준비 상태는 [연동 코드](../src/search/kakaoTransit.ts)와 [검사](../tests/kakaoTransit.test.ts)를 참조한다. 검증용 응답 통과와 승인된 실제 서비스 호출 성공을 구분한다.
